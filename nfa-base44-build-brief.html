BREAKING NEWS BANNER

  • Full-width solid red bar (#cc0000) above hero sections

NEW FEATURE

Admin: Create New Investigation Tool HIGH

Currently there is NO way for the admin to create a new investigation from inside the app. This is the most critical missing feature. The admin portal must include a full investigation builder with the following components:

REQUIRED FIELDS FOR EACH INVESTIGATION

  • Investigation Title — text input (e.g. "The Counsel of Conflict")
  • Subtitle / Case Name — text input (e.g. "Stone Creek Ranch HOA")
  • Location / Jurisdiction — text input (e.g. "Harris County, TX")
  • Published Date — date picker
  • Status — dropdown: Active / Ongoing / Closed / Developing
  • Tags — multi-select (HOA, Corruption, Election, Financial Fraud, etc.)
  • Thumbnail Image — image uploader for the case card photo
  • Case Summary — short text (2-3 sentences, shown on the card)
  • Full Report / Narrative — large rich-text editor / sandbox where admin types the full investigation story with dates, times, names, and narrative. Should support bold, italic, headers, bullet lists at minimum.
  • PDF Exhibits Uploader — ability to upload multiple PDF files as exhibits (Exhibit A, B, C, etc.)
  • PDF Viewer — uploaded PDFs display inline on the investigation page (browser-native, no download required)
  • Image Exhibits — ability to upload image files as evidence exhibits alongside PDFs
  • Exhibit Labels — each uploaded file gets a label (e.g. "Exhibit A — Notice of Special Hearing")

HOW IT SHOULD DISPLAY ON THE PUBLIC PAGE

  • Each investigation saved in admin appears as a case card on investigations.html
  • Clicking "READ FULL INVESTIGATION" opens the full report page
  • Full report shows: headline, narrative text, then exhibit boxes in order
  • PDF exhibits display inline using browser PDF viewer — no download prompts
  • Image exhibits display as full-width evidence boxes with labels
